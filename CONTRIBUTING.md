# Участие в разработке

## Подготовка

Нужны Python 3.12+ и Node.js 16+. Установите dev-инструменты в изолированном окружении:

```sh
npm ci
python -m venv .venv
```

Активируйте `.venv` для своей оболочки, затем выполните:

```sh
python -m pip install -r requirements-dev.txt
npm test
```

## Перед коммитом

```sh
npm run format
npm test
npm run format:check
```

Если окружение не активировано, Black можно вызвать напрямую: `.venv/Scripts/python -m black doctor-chess-site` на Windows или `.venv/bin/python -m black doctor-chess-site` на Linux/macOS.

## Соглашения

- Один коммит — одна понятная причина изменения. Не смешивайте массовое форматирование и новые механики.
- Изменение правил должно проходить общий движок: браузер не определяет результат сетевой партии самостоятельно.
- Для асинхронных ответов проверяйте актуальность режима, партии и поколения Worker.
- Новые серверные мутации проверяют текущую сессию, участника, очередь хода и срок действия объекта.
- Тесты используют временную SQLite-базу. Не запускайте их на `data/chess.sqlite3` пользователя.
- Не добавляйте в Git базы, cookie, токены, `.env`, результаты браузерных проверок и локальные окружения.
- Сохраняйте доктора в наушниках и красно-бело-золотую палитру. Центральные подписи должны читаться без масштабирования.
