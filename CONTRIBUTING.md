# Участие в Doctor Chess

Материал для участников закрытого репозитория Doctor Chess. Предложения, исправления и улучшения интерфейса принимаются через [Issues](https://github.com/ubica1/doctor-chess/issues) и pull request.

## Обратная связь

Опишите ожидаемый результат, фактическое поведение и последовательность действий. Для ошибок интерфейса укажите устройство и браузер; приложите скриншот без приватных данных. Для шахматной ошибки полезны ссылка на завершённую партию, PGN или FEN.

Пароли, cookie, токены сессий и базы аккаунтов нельзя публиковать. Сообщения об уязвимостях — по [правилам безопасности](SECURITY.md).

## Изменения кода

- Один pull request решает одну связную задачу. Описание объясняет результат для игрока и способ проверки.
- Сервер подтверждает ходы, время и результат сетевой партии. Клиентское отображение не заменяет эту проверку.
- Запоздалые ответы не должны менять другую партию, позицию или выбранный режим.
- Повтор действия не создаёт вторую игру и не пересчитывает рейтинг повторно.
- Изменения схемы сохраняют существующие профили и партии.
- Проверки используют временные данные. Пользовательские базы и секреты не входят в репозиторий.
- Обязательные проверки правил, интерфейса, HTTP API и форматирования выполняются в GitHub Actions. Для изменения поведения нужны соответствующие регрессионные сценарии.

## Язык и оформление

Интерфейс обращается к игроку: объясняет действие, результат и способ продолжить. Служебные команды и детали инфраструктуры не относятся к игровым экранам. Сохраняйте читаемые подписи, красно-бело-золотую палитру и DJ Doctor в наушниках. Ключевые действия должны быть доступны мышью, клавиатурой и касанием.

Уважайте лицензии сторонних компонентов и сохраняйте их авторство. Изменения Doctor Chess публикуются на условиях [GNU GPLv3](LICENSE).
