# Doctor Chess

Локальный шахматный клуб. Python 3.12+ и Node.js 16+; установка пакетов не нужна.

Запуск из этой папки:

    python server.py

Открыть http://localhost:4173. Регистрация по имени и паролю, без внешней авторизации.
Для проверки подбора соперников откройте два разных браузера (или обычное и приватное окно), создайте два профиля и выберите одинаковый контроль. Боты в очередь не добавляются.

Функции: серверная проверка ходов, часы и добавление времени, восстановление партии после перезагрузки, сдача, предложение ничьей, отдельный Elo (K=24, старт 1200) для пули/блица/рапида/классики, профиль и таблица рейтингов. Домашняя игра без рейтинга и часов, задача на мат.

Профили, сессии, партии и рейтинги сохраняются в data/chess.sqlite3. Пароли хешируются PBKDF2-SHA256 с уникальной солью, сессии в HttpOnly cookies. Данные не находятся в папке статических файлов и исключены из Git. Для резервного копирования остановите сервер и сохраните папку data.

Проверки:

    node test-engine.cjs
    python -m unittest test_server -v

Интеграционные тесты используют отдельную временную базу. Сервер слушает только 127.0.0.1. Текущая версия предназначена для localhost; доступ из интернета и мобильное приложение требуют отдельного размещения и дальнейшей разработки. Старая публикация Sites содержит предыдущий статический прототип.

Публичные профили: /player/имя, каталог: /players. Просмотр доступен без регистрации. Эмблему и описание меняет только владелец. История показывает завершённые партии, поддерживает фильтр контроля и страницы по 12 партий. На localhost ссылки работают на этом компьютере; для внешнего доступа сервер нужно разместить отдельно.

Управление доской: два клика или перетаскивание мышью/касанием. Неверный ход возвращает фигуру на место; Escape отменяет выбор. Звук ходов включается кнопкой ♪. Домашняя позиция сохраняется в текущей вкладке, режим и контроль — в браузере. При переходе из активной сетевой партии в домашний режим её часы продолжают идти; над режимами появляется кнопка возврата.

Регрессионные проверки клиента: node test-client.cjs (запоздалые ответы сервера, выбор режима/контроля, мгновенный ход и откат, постоянные элементы доски, перетаскивание и отмена).

Большой этап: тренировочная студия DJ Doctor

- «С доктором»: три учебных уровня, выбор цвета, отмена пары ходов, продолжение после перезагрузки. Компьютер считает в Web Worker, не замораживая доску. Это локальный учебный движок (ограниченный поиск alpha-beta), без заявленного Elo и без влияния на сетевой рейтинг.
- Запись партии использует SAN: взятия, шах/мат, рокировка и превращение. Нажатие на ход и стрелки внизу доски перематывают позицию, не изменяя текущую игру. Стрелки клавиатуры также поддерживаются. При просмотре активной сетевой партии её часы продолжают идти.
- Учебные подсказки с оценкой позиции доступны в тренировках и разборе. В активной рейтинговой партии подсказки отключены.
- «Мои партии»: до 40 домашних записей в localStorage этого браузера, плюс завершённые сетевые партии из профиля. PGN можно скачать для переноса в другие шахматные программы. Очистка данных браузера удаляет локальную библиотеку; PGN сохраняется отдельно.
- Завершённую сетевую партию можно открыть без входа по /review/ID. В профиле результат партии ведёт к разбору. Незавершённые партии через этот API недоступны.

Проверка учебной студии: node test-study.cjs. Проверка клиентских состояний и отмены Worker: node test-client.cjs. Интеграционные проверки сервера: python -m unittest test_server -v.

Импорт и анализ вариантов

- Кнопка «Импорт»: вставка PGN/FEN и чтение .pgn до 128 КБ. Поддерживается одна основная линия до 400 полуходов. Комментарии, NAG и вложенные варианты PGN пропускаются; это явно указано перед импортом. Неподходящий ход отклоняет весь импорт.
- FEN проверяет королей, пешки, рокировку, взятие на проходе, очередь и счётчики. Начало с хода чёрных и произвольного номера сохраняется в SAN/PGN и после ходов.
- «Вариант на доске» создаёт независимую учебную линию из показанной позиции. Исходная партия и курсор просмотра сохраняются; кнопка «Вернуться к партии» их восстанавливает. Открытый вариант сохраняется в текущей вкладке после перезагрузки. Это одна рабочая линия, а не дерево вариантов PGN.
- «С доктором отсюда»: тренировочная партия из выбранной позиции, пользователь играет за сторону, которой сейчас ходить. Исходная запись сохраняется для возврата. «Скопировать FEN» копирует именно показанную позицию.
- В активной рейтинговой партии импорт не меняет серверную игру; создание варианта и тренировка из её позиции отключены.
- Палитра и размеры текста централизованы в dist/theme.css. Используются Arial/Helvetica и Georgia/Times New Roman без загрузки внешних шрифтов. Доктор в наушниках сохранён.
