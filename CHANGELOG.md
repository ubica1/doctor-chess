# Изменения

## 0.5.0 — 4 ноября 2026

### Игра

- Приглашения другу по ссылке: выбор цвета и контроля, комната ожидания, отмена и срок действия.
- Дружеские партии без Elo и отдельная метка в истории.
- Согласованный реванш со сменой цветов и сохранением типа партии.
- Отзыв своего предложения ничьей и отклонение предложения соперника.
- Предварительный ответ с проверкой после подтверждённого хода соперника.

### Исправления

- Цвет против бота можно менять после начала игры. Предыдущая тренировка сохраняется перед подтверждённым перезапуском.
- Настройки учебного соперника сохраняются в браузере.
- Часы проигравшего по времени показывают ноль после фиксации результата.
- Одно приглашение не создаёт несколько игр при одновременном принятии.

### Репозиторий

- Исходники собраны в один обычный Git-репозиторий; рабочие базы и служебные файлы исключены.
- Читаемый формат исходников, закреплённые инструменты, единая команда проверок.
- GitHub Actions для Windows/Linux и Node.js 22/24.
- README с фирменной обложкой, документация API и архитектуры.

## Ранее реализованная платформа

Локальный сервер, регистрация и публичные профили, случайный подбор, Elo в четырёх категориях, плавная доска с перетаскиванием, DJ Doctor, разбор и библиотека, SAN/PGN/FEN, импорт и отдельная линия анализа. Эта работа сохранена исходным коммитом `feat: import existing Doctor Chess platform`, без выдуманной ретроспективной истории.
