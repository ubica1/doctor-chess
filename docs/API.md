# HTTP API

Базовый адрес сервиса: `https://doctor-chess.ru/api`. JSON в UTF-8. Мутации используют `POST` и `Content-Type: application/json`.

Сессия передаётся HttpOnly cookie `dc_session`. API не возвращает пароль, соль или токен сессии в публичных профилях. Для браузерных POST проверяется совпадение `Origin` с текущим сервером. Статические файлы находятся только в `dist/`; база сессий оттуда не раздаётся.

## Ошибки

Форма: `{ "error": "Понятное сообщение" }`.

| Код | Значение                                                                     |
| --- | ---------------------------------------------------------------------------- |
| 400 | Некорректные данные или недопустимый шахматный ход.                          |
| 401 | Требуется вход.                                                              |
| 403 | Не тот источник запроса или реванш предназначен другому игроку.              |
| 404 | Объект не существует либо не доступен текущему пользователю.                 |
| 409 | Игрок занят, не его ход, приглашение уже занято или партия ещё не завершена. |
| 410 | Приглашение отменено или просрочено.                                         |
| 413 | Слишком большой JSON-запрос.                                                 |
| 429 | Слишком много попыток входа/регистрации.                                     |
| 503 | Проверка хода недоступна. Если партия продолжается, повторите ход.           |

## Аккаунт и сообщество

| Метод | Путь                                     | Назначение                                                                                              |
| ----- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| POST  | `/register`                              | `{username,password}`. Имя: 3–24 буквы/цифры/`_`/`-`; пароль: 8–128 символов.                           |
| POST  | `/login`                                 | `{username,password}`. Устанавливает cookie сессии.                                                     |
| POST  | `/logout`                                | Удаляет текущую сессию и ожидание в очереди.                                                            |
| GET   | `/me`                                    | `{user}` либо `{user:null}`.                                                                            |
| POST  | `/profile`                               | `{bio,avatar}`. Меняет только профиль текущей сессии. Эмблема: `crane`, `dragon`, `bamboo`, `mountain`. |
| GET   | `/players?search=...`                    | До 50 последних игроков, поиск по имени.                                                                |
| GET   | `/players/:username?page=1&category=all` | Публичные рейтинги, статистика и 12 завершённых игр на страницу.                                        |
| GET   | `/leaderboard`                           | Таблицы `bullet`, `blitz`, `rapid`, `classical`; только игроки с рейтинговыми партиями.                 |

## Партия

Имена сопоставляются по Unicode-ключу `NFKC(name).casefold()`, а отображаемое написание сохраняется. Канонический дубль при регистрации возвращает 409. `username`, `password`, `bio`, `avatar` при передаче должны быть строками; другие JSON-типы возвращают 400 без изменения аккаунта или сессии. Пароль не преобразуется и не обрезается; описание — до 240 символов. Изменения схемы сохраняют существующие профили и партии.

| Метод | Путь            | Назначение                                                                                                       |
| ----- | --------------- | ---------------------------------------------------------------------------------------------------------------- |
| GET   | `/state`        | Текущий пользователь, последняя/активная игра и очередь.                                                         |
| GET   | `/play/:id`     | Собственная игровая комната: состояние и часы конкретной партии. Без входа — 401, для постороннего игрока — 404. |
| POST  | `/queue`        | `{control}`. Создать/продолжить случайный рейтинговый подбор.                                                    |
| POST  | `/cancel`       | Отменить случайный поиск.                                                                                        |
| POST  | `/move`         | `{game,from,to,promotion}`. Индексы 0–63, `a8=0`, `h1=63`. `promotion`: `q/r/b/n`, по умолчанию `q`.             |
| POST  | `/resign`       | `{game}`. Сдаться в собственной активной партии.                                                                 |
| POST  | `/draw`         | `{game}`. Предложить ничью; при предложении соперника — принять её.                                              |
| POST  | `/draw-decline` | `{game}`. Отклонить чужое предложение или отозвать своё.                                                         |
| GET   | `/games/:id`    | Публичная запись **только завершённой** партии: имена, ходы, контроль, результат и тип.                          |

Объект активной игры содержит `state`, `moves`, `last`, `clocks`, `you`, `white`, `black`, `result`, `offer`, `kind` и `rematch`. Время считается сервером; клиент не присылает новые часы, результат или рейтинг.

Для принятого хода учитывается время получения полного JSON-запроса; внутреннее ожидание и проверка Node не списываются. Добавление начисляется только принятому ходу. Просроченный запрос сначала завершает партию по времени. Сдача и принятие ничьей сохраняют окончательные часы; повтор завершения не меняет рейтинг. Часы не бывают отрицательными.

Публичное чтение профиля и завершённой записи не требует входа. Получить чужую активную доску через `/games/:id` нельзя.

Браузерный адрес `/game/:id` открывает комнату участника через `/api/play/:id`. Начало сетевой игры и реванш переводят туда автоматически. Возврат на главную не останавливает серверные часы. `/play/computer`, `/play/local`, `/play/puzzle` и `/play/analysis` открывают локальный стол: позиция восстанавливается в той же вкладке из sessionStorage, ссылка не переносит её в другой браузер.

## Приглашения и реванши

| Метод | Путь                        | Назначение                                                                                         |
| ----- | --------------------------- | -------------------------------------------------------------------------------------------------- |
| POST  | `/challenges`               | `{control,color}`. `color`: `w`, `b`, `random`. Дружеская игра без рейтинга, срок 30 минут.        |
| GET   | `/challenges/:token`        | Имя создателя, контроль, цвет, статус и срок. Без приватных данных аккаунта.                       |
| POST  | `/challenges/:token/join`   | Принять свободное приглашение. Создатель не может принять своё; оба игрока должны быть свободны.   |
| POST  | `/challenges/:token/cancel` | Создатель отменяет ожидающее приглашение.                                                          |
| POST  | `/games/:id/rematch`        | Первый участник предлагает реванш, второй этим же действием принимает. Срок предложения — 5 минут. |

Статусы приглашения: `pending`, `accepted`, `cancelled`, `expired`. Повторный запрос принявшего игрока возвращает ту же игру. Третий игрок получает ошибку.

Реванш доступен только исходным участникам после завершения игры. Цвета меняются; контроль и `kind` сохраняются. Вход в другую игру отменяет прежнее ожидание.

## Адреса интерфейса

- `/` — игровая комната.
- `/players` — книга игроков.
- `/player/:username` — публичный профиль.
- `/review/:id` — разбор завершённой сетевой партии.
- `/invite/:token` — приглашение и ожидание друга.

Эти адреса возвращают клиентскую страницу; JSON-данные запрашиваются отдельно через API.

После завершения рейтинговой партии объект `game` содержит `ratingChange`: ключи `w` и `b`, у каждого `before`, `after`, `delta`. Это сохранённый итог именно этой партии. Для старых записей и дружеских игр поле может быть `null`.

## Связь и дружеские действия

`GET /lobby` возвращает `{online, waiting}`: число недавно активных авторизованных игроков и количество ожидающих по каждому контролю. Записи очереди старше 15 секунд не учитываются. Имена, идентификаторы и данные сессий в ответ не входят. Проверка присутствия не записывает историю посещений в базу.

Объект партии дополнен `presence: {w, b}`, `takeback`, `takebackDeclined` и `giftsLeft`. `presence` — наличие авторизованного запроса игрока за последние 20 секунд; это индикатор связи, а не основание для завершения игры.

| Метод | Путь                | Тело и результат                                                                                                                                                                                       |
| ----- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| POST  | `/give-time`        | `{game, token}`. Подарить сопернику 15 секунд; `token` — уникальная строка из 8–64 букв, цифр, `_` или `-`. Повтор того же токена не добавляет время повторно. Не более 20 подарков от каждого игрока. |
| POST  | `/takeback-request` | `{game, ply}`. Попросить вернуть собственный последний ход; `ply` должен совпадать с числом полуходов текущей позиции.                                                                                 |
| POST  | `/takeback-accept`  | `{game, offer}`. Соперник принимает действующую просьбу по её ID.                                                                                                                                      |
| POST  | `/takeback-decline` | `{game, offer}`. Соперник отклоняет просьбу или автор отзывает её.                                                                                                                                     |

Эти действия доступны только участникам активной дружеской партии. В рейтинговой партии — 403; для постороннего аккаунта — 404; для завершённой игры или устаревшей просьбы — 409. Автор просьбы не может принять её сам. После отказа повторная просьба в той же позиции отклоняется. Любой новый ход отменяет просьбу.

Возврат восстанавливает фигуры, очередь, рокировки, взятие на проходе и историю позиции. Потраченное время остаётся списанным; добавление за отменённый ход снимается. Повторное согласие не отменяет ещё один ход. Подарок времени не возобновляет завершённую партию.

`POST /challenges` дополнительно принимает `opponent` — имя выбранного соперника. Такой вызов может принять только этот аккаунт. В объекте приглашения `target` содержит имя адресата либо null, `can_join` показывает право текущего игрока принять приглашение. Реванш также адресуется исходному сопернику.

## Исследования

| Метод | Путь                         | Назначение                                                                        |
| ----- | ---------------------------- | --------------------------------------------------------------------------------- |
| GET   | `/studies?page=1&archived=0` | Личные тетради текущего профиля, по 20 на страницу. `archived=1` открывает архив. |
| GET   | `/studies/:id`               | Документ владельцу или читателю ссылки при `public=true`.                         |
| POST  | `/studies`                   | Создание: `{title, description, public, document, clientKey}`.                    |
| POST  | `/studies/:id`               | Сохранение владельцем: `{title, description, public, document, revision}`.        |
| POST  | `/studies/:id/archive`       | Архивирование владельцем: `{revision}`. Закрывает чтение по ссылке.               |
| POST  | `/studies/:id/restore`       | Восстановление из архива владельцем: `{revision}`.                                |

ID — 24 шестнадцатеричных символа. `public` — boolean, по умолчанию false; это доступ к конкретной тетради по ссылке. Архив сохраняет настройку доступа: после восстановления ранее открытая тетрадь снова доступна читателям. Чтение недоступной тетради и попытка записи чужой возвращают 404. Список и запись требуют сессию; ответ чтения содержит `own`, `author`, метаданные и документ, без внутренних идентификаторов владельца и ключа создания.

`clientKey` — стабильный идентификатор черновика из 8–64 латинских букв, цифр, `_` и `-`. Повтор создания с тем же ключом возвращает уже созданную запись. Обновление и архивирование увеличивают целую `revision`; несовпадение возвращает 409. В профиле допускается 100 записей, включая архив.

Документ: `{version:1, start:FEN, nodes:[{id,parent,move,comment,nag}]}`. Первый узел `root` имеет `parent:null, move:null`; остальные ссылаются на существующий родительский узел. Ход — `{from,to,promotion?}` с индексами клеток общего движка. До 400 узлов, до 200 полуходов в ветке, комментарий до 2000 символов, NAG 0–6. Название после удаления крайних пробелов — 1–80 символов, описание — до 400. Сервер заново проверяет легальность всего дерева.

Только создание и обновление тетради допускают JSON до 200000 байт; прочие POST сохраняют предел 10000 байт. Прокси допускает 256 КБ. Валидация дерева не удерживает блокировку игровых запросов; при двух одновременных проверках следующая получает 429 и может повторить запрос позднее. Невалидное дерево возвращает 400, слишком большой запрос — 413.

Узел исследования может дополнительно содержать `shapes`: до 64 объектов `{from,to,color}`. Координаты — целые индексы клеток 0–63; одинаковые `from` и `to` задают круг, разные — стрелку. Цвет: `green`, `red`, `gold`, `blue`. В пределах одного узла пары клеток не повторяются. Отсутствующее поле означает отсутствие пометок; старые тетради совместимы. Доступ и номер редакции применяются к пометкам так же, как к комментариям.

## Зрительские трансляции

| Метод | Путь                    | Назначение                                                                                                                                                                              |
| ----- | ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GET   | `/watch`                | До 20 последних активных рейтинговых партий, для которых оба участника разрешили просмотр. Доступно без входа.                                                                          |
| GET   | `/watch/:id`            | Отдельное представление партии: фигуры, ходы, часы, имена, эмблемы, рейтинг, результат и причина. Активная закрытая трансляция — 404. Завершённая запись доступна как публичная партия. |
| POST  | `/games/:id/spectators` | `{enabled:boolean}`. Участник задаёт только своё согласие. Повтор запроса идемпотентен. Нужна сессия; постороннему — 404, завершённой партии — 409.                                     |

В ответе участникам `game.watch` содержит `w`, `b`, `enabled` (оба согласны), `listed` (оба согласны и партия рейтинговая). Согласие не наследуется реваншем и не изменяет часы или рейтинг. По умолчанию разрешений нет. Дружеские партии не входят в общий список даже после согласия.

У зрителя отсутствуют `you`, предложения ничьей/возврата, подарки времени, токены действий, присутствие игроков и внутренние ID профилей. `serverTime` — время формирования ответа; `clocks` уже учитывают прошедшее время текущего хода. При потере связи клиент ограничивает экстраполяцию часов 12 секундами и не объявляет исход. Ответы API не кешируются.

`POST /cancel` удаляет ожидание и возвращает `{ok:true, game}`: `game` содержит уже начавшуюся партию, если подбор успел завершиться. Истёкшее ожидание (15 секунд без опроса) удаляется перед обновлением `/state`; для нового поиска нужен новый запрос `/queue`.

Запрос хода с `promotion=r|b|n` принимается только для пешки на последней горизонтали; значение `q` остаётся совместимым значением по умолчанию. Лимит входа за прокси разделён по проверенному адресу клиента. При занятости двух расчётов авторизации API возвращает 429 с предложением повторить запрос.
