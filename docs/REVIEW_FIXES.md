# Исправления по аудиту от 5 ноября 2026

Работа охватывает FIX-01–FIX-07 из пакета аудита. Рекомендации FEAT для 0.7 не входят в этот выпуск.

## Часы и результат

Полный JSON-запрос получает серверную отметку времени до ожидания общего lock. Для принятого хода списывается время до этой отметки; ожидание и расчёт Node не расходуют часы. Часы соперника запускаются после успешной проверки. Неверный ход не останавливает часы и не получает добавление. Просроченный запрос завершает партию до проверки хода. Сдача и принятие ничьей фиксируют часы на момент получения запроса, флаг имеет приоритет. В базе сохраняются итоговые часы как рейтинговых, так и дружеских игр. Повтор завершения не меняет Elo.

Возможность мата по времени учитывает материал обеих сторон: одинокого короля, одиночного коня, цвет полей слонов, чужие пешки и лёгкие фигуры. Старые позиции с недостаточным материалом завершаются ничьей даже до флага. Это проверка материала, а не полный поиск всех возможных последовательностей: произвольные заблокированные «мёртвые» позиции с пешками и вынужденными линиями автоматически не распознаются. Это оставшееся ограничение FIX-01 и существующего движка.

## Имена и миграция

Отображаемое имя сохраняется отдельно от `username_key = NFKC(username).casefold()`. Новый ключ используется при входе, поиске, открытии профиля и проверке уникальности. Пароль не обрезается и не нормализуется. Допустимы 3–24 Unicode-буквы/числовых символа, `_` и `-` (семантика Python `\w`); пробелы по краям имени удаляются. Поля имени, пароля, описания и эмблемы принимают только строки; описание ограничено 240 символами. Пропущенное поле профиля сохраняет прежнее значение.

При следующем запуске обновлённого сервера:

1. Миграция проверяет канонические конфликты, прежде чем менять схему ключей.
2. При конфликте сервер останавливается и перечисляет имена и ID. Автоматического объединения нет. Остановите все серверы, скопируйте папку `data`, выберите с владельцами новые имена и измените только `users.username` соответствующих ID через SQLite. Затем повторите запуск. ID, партии, рейтинги и пароли менять не нужно.
3. Перед изменением непустой базы SQLite backup API создаёт рядом файл `chess.sqlite3.before-unicode-<id>.sqlite3`, включая данные WAL. Имя резервной копии уникально; предыдущие копии не перезаписываются.
4. Добавление ключей и уникального индекса выполняется в транзакции. Повтор успешной миграции ничего не меняет.

Работающий до обновления процесс Python продолжает использовать старый серверный код до перезапуска. Интерфейс обновляется при перезагрузке страницы. В ходе проверки пользовательская база и работающий процесс не изменялись; HTTP-тесты использовали временные базы и свободные порты.

## Импорт и библиотека

`g1f3q` и `e2e4n` отклоняются. Для настоящего превращения поддерживаются `q/r/b/n`; пропущенный суффикс означает ферзя. Ошибка импорта не изменяет текущую доску.

Сетевые партии подгружаются по 12, с дедупликацией по ID, состояниями загрузки/пустого списка/ошибки и повтором той же страницы. Ошибка не стирает уже показанные партии. Домашние записи проверяются перед отображением. Лимит 40 и вытеснение старой записи объяснены рядом с сохранением и в библиотеке; отдельный PGN-экспорт доступен у каждой исправной записи.

## Проверка

- `npm test`: общие правила, Stockfish, импорт, клиентские состояния и 12 HTTP/migration unittest.
- Новые регрессии: задержанный валидатор, уже просроченный запрос, материал обеих сторон, повторное завершение, часы сдачи/ничьей в двух типах игры, кириллица и неверные JSON-типы без побочных изменений, резервная копия/конфликт/повтор миграции.
- Клиентские проверки: 25 сетевых партий на трёх страницах, сбой второй страницы и повтор без дублей, повреждённые домашние записи.
- Расширенные скрипты аудита: 41 API-проверка и 7 проверок движка. Два ожидания теста задержанного валидатора адаптированы к явно выбранному контракту времени получения запроса: своевременный ход принят и остаток положителен. Просроченный запрос отдельно проверяется штатным набором.
- Браузер: ход e4 и ответ Доктора, скрытие приветствия, меню и Escape с возвратом фокуса; геометрия активной игры при 360×800, 390×844, 768×1024, 1366×768 CSS px. Доска, часы, подсказка и отмена видимы одновременно, горизонтального переполнения нет.

Реальные мобильные устройства, скринридер и масштаб текста 200% отдельно не проверялись. CSS разрешает вертикальную прокрутку и перенос элементов, не фиксирует высоту страницы.
