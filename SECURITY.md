# Границы безопасности

По умолчанию Doctor Chess слушает **localhost**, `127.0.0.1`. Для небольшого публичного клуба подготовлена [конфигурация VPS](docs/DEPLOYMENT.md): Caddy с HTTPS, внутренний порт приложения и постоянный том SQLite. Публичный Origin задаётся явно, cookie сессии получают Secure. Один процесс приложения обслуживает все партии; масштабирование и усиление против массовой нагрузки требуют отдельной работы.

В приложении используются PBKDF2-SHA256 с уникальной солью, HttpOnly/SameSite cookie, хеширование сохранённых токенов сессии, проверка Origin для браузерных POST и серверная проверка шахматных ходов. Приватные поля аккаунта не включаются в публичные профили и записи партий.

`doctor-chess-site/data` содержит приватные пользовательские данные. Не прикладывайте эту папку, cookie или пароли к публичным issue. Для сообщения об ошибке достаточно описания сценария и обезличенных шагов воспроизведения. Чувствительные сведения передавайте владельцу репозитория приватно.

Публикация исходного кода не публикует локальную базу. Перед переносом на публичный сервер нужно отдельно проработать HTTPS, ограничение нагрузки, управление сессиями, резервное копирование и эксплуатацию.
